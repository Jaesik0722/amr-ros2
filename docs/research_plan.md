# 연구 계획: 견인형 AMR 논문 3편 (SCIE Q1/Q2)

이 플랫폼만의 강점에서 출발한다. 일반적인 tractor-trailer 제어나 GS 디지털 트윈은 이미 많이
연구되어 있으므로, 기여점은 아래 강점에 묶어야 Q1 리뷰에서 새로움을 인정받는다.

**플랫폼 강점**
1. **구동형 2-DOF 히치**(yaw/pitch, Dynamixel XM540): 히치 yaw로 카트를 직접 조향할 수 있다. 일반 견인 AMR은 수동 연결이다.
2. **히치 자기감지**: 서보 전류와 엔코더로 히치 각 β와 하중을 측정한다(결합 판정에 이미 사용).
3. **off-axle 연결**: 히치가 바퀴축 뒤 0.177 m에 있다. β̇ = ω(1 + (d/L)cosβ) − (v/L)sinβ.
4. **실측 기준값과 같은 인터페이스의 시뮬레이터**: indoor GPS(로봇·카트 위치)와 Isaac Sim이 같은 ROS 2 인터페이스를 쓴다.

## 논문 1: 히치 자기감지 기반 미지 카트 식별과 능동 히치 견인 제어
- **문제**: 공장 카트는 질량, 무게중심, 바퀴 구성(고정 2 + 캐스터 2, 캐스터 4)이 제각각이다.
  수동 견인은 카트가 바뀌면 경로 추종이 흔들리고, 좁은 통로에서 카트가 바깥으로 쓸고 나간다(off-tracking).
- **방법**
  1. 결합 직후 짧은 가진 동작(전후진, 히치 yaw 스윕)으로 히치 전류와 β를 측정해 카트 질량, 굴림 저항,
     바퀴 구성(조향 가능 여부)을 온라인으로 추정한다.
  2. 추정한 모델로 MPC(또는 MPPI)가 (v, ω, 히치 yaw)를 함께 최적화해 카트 off-tracking과 추종 오차를 줄인다.
- **비교 대상**: 수동 히치 + Nav2 MPPI(현재 구현, `passive_yaw`), 고정 파라미터 MPC, 능동 히치 + 식별 없음
- **지표**: 카트 경로 RMS 오차(indoor GPS), 최대 off-tracking, 통로 통과 성공률, 히치 전류 피크
- **실험**
  - 시뮬레이션: 카트 질량 10~60 kg, 무게중심, 캐스터 구성, 굴림 저항을 무작위로 바꿔 대량 실험
  - 실물: 카트 3~4종, S자와 직각 코너 코스
- **투고처**: IEEE T-ASE, IEEE/ASME TMECH, IEEE RA-L, Robotics and Autonomous Systems
- **필요한 개발**
  - [ ] 시뮬레이터: 카트 파라미터 무작위화(`world.py`의 `_build_cart` 인자화), 캐스터 4개 구성(전부 swivel)
  - [ ] 히치 yaw 능동 명령 인터페이스(지금은 위치 명령 + passive 모드만 있다)
  - [ ] 식별기(가진 시나리오 + 최소제곱/EKF), MPC 노드(Python, acados 또는 CasADi)
  - [ ] β와 카트 상태 추정(히치 엔코더 + 후방 카메라 보조)

## 논문 2: 실제 공장 GS 트윈에서 학습한 마커 없는 카트 결합
- **문제**: 지금 결합은 ArUco 마커에 의존한다. 현장 모든 카트에 마커를 붙이기 어렵다.
- **방법**
  1. 실제 공장을 Gaussian Splatting으로 시뮬레이터에 옮긴다(화면은 GS, 충돌과 라이다는 메시, 카트는 물리 객체). [gaussian_splatting.md](gaussian_splatting.md)
  2. 후방 D435 영상과 히치 전류만으로 결합하는 정책을 학습한다(시각 서보 또는 강화학습, Isaac Lab).
  3. 실물에 추가 학습 없이 적용한다(zero-shot).
- **기여점**
  - GS 트윈과 일반 렌더링 시뮬레이터에서 학습한 정책을 실물에서 비교한다.
  - 같은 위치에서 시뮬레이션과 실물의 검출 오차와 결합 성공률을 비교해 시뮬레이션-실물 차이를 정량화한다.
- **비교 대상**: ArUco 기반(현재), 일반 시뮬레이터 학습, GS 트윈 학습
- **지표**: 결합 성공률, 최종 정렬 오차(갈고리와 바 사이), 소요 시간, 실패 유형
- **투고처**: IEEE RA-L, RAS, IEEE Access(Q2, 빠른 심사)
- **필요한 개발**
  - [x] 촬영·변환 도구(`amr_capture`), Isaac에 GS와 충돌 메시 로딩(`--env-usd`, `--env-collision`)
  - [ ] 현장 촬영과 3DGRUT 학습
  - [ ] 카트 3D 모델(실제 카트 측정), 정책 학습 환경(Isaac Lab), 실물 실험

## 논문 3: 형상이 바뀌는 견인 시스템의 좁은 통로 경로계획
- **문제**: 결합 전후로 로봇의 형상이 바뀌고, 견인 중에는 카트가 쓸고 지나가는 영역(swept volume)이 β에 따라 달라진다.
  Nav2는 고정 footprint를 가정한다(지금은 볼록 다각형 근사).
- **방법**: 로봇+카트 운동학(off-axle, 능동 히치 포함)을 상태 격자 계획(Smac lattice 확장 또는 자체 플래너)에
  넣어 swept volume을 고려한다. 능동 히치를 쓰면 같은 통로를 더 좁은 회전으로 지나갈 수 있음을 보인다.
- **비교 대상**: 볼록 footprint + MPPI(현재), 수동 히치 운동학 플래너, 능동 히치 플래너
- **지표**: 통과 가능한 최소 통로 폭, 계획 시간, 충돌 없는 성공률, 경로 길이
- **실험**: 시뮬레이션(창고와 GS 현장 트윈)과 실물(테이프로 통로 폭 조절)
- **투고처**: IEEE RA-L, Journal of Field Robotics, IEEE T-ITS 또는 Applied Sciences/Sensors(Q2)
- **필요한 개발**: 논문 1의 운동학 모델과 히치 yaw 인터페이스를 재사용한다.
